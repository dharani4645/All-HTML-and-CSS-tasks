# HTML & CSS Web Development Tasks

## 📌 Project Overview

This repository contains a collection of **20 HTML and CSS web development tasks** created as part of my web development practice and training.

Each task focuses on designing a different type of real-world webpage using **HTML5 and CSS3**. The projects cover portfolio websites, business pages, forms, dashboards, landing pages, e-commerce interfaces, and corporate websites.

The main goal of these tasks is to develop practical skills in **webpage structure, responsive design, layouts, navigation, forms, cards, sections, and modern UI design**.

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* Responsive Web Design
* CSS Flexbox
* CSS Grid
* CSS Media Queries
* Semantic HTML
* Modern UI Design

1. Clone or download this repository.
2. Open the required task folder.
3. Locate the `index.html` file.
4. Open `index.html` in any modern web browser.
5. The selected webpage will be displayed.

No additional installation or dependencies are required.
